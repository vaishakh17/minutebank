 MinuteBank

 Project Overview
MinuteBank is a web-based banking application developed using Java and Spring Boot. 
It provides user authentication and time-entry management features through REST APIs and a web interface.

## Technologies Used
- Java
- Spring Boot
- Spring Data JPA
- MySQL
- Spring Security
- JWT Authentication
- HTML
- CSS
- JavaScript
- Maven

## Features
- User registration and login
- JWT-based authentication
- Secure API access
- Time-entry management
- Weekly reporting
- Input validation and exception handling
- MySQL database integration

## Configuration
Configure your database credentials and JWT secret using environment variables:

- `DB_PASSWORD`
- `JWT_SECRET`

## Running the Application

1. Clone the repository.
2. Configure your MySQL database.
3. Set the required environment variables.
4. Run the application using Maven:

```bash
mvn spring-boot:run
```

5. Access the application at:

`http://localhost:8081`
